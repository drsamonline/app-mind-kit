Open Mind Kit

This is a notebook with a clock in it. It is not therapy, not a diagnosis, and not a crisis service. If things are bad now, that belongs with a clinician or a crisis line — not with an app.

Status Built and working offline: a worry written down, given a time, and set aside until then — never parked without a window; and a sleep diary that computes sleep efficiency from the times you enter (nine hours in bed, six asleep, 67%) and shows which logged behaviour preceded the lower nights, with the counts.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: any advice. No CBT-I schedule, no restriction protocol, no recommendation — the spec forbids all three and the clinical decision stays with the clinician.

What it does

  • A worry goes in a window with a time. It does not come back before then, and it does come back after.
  • Sleep efficiency from times: time asleep over time in bed, per night and averaged.
  • Which logged behaviour preceded the lower-efficiency nights — with the counts, and named as an association.

What it will not do

  • Park a worry with no time. A worry with no window is the thing this app exists to prevent.
  • Solve the worry. Closing the window puts it down; it was never the job to fix it.
  • Call a night good or bad. It shows arithmetic on your own times.
  • Diagnose insomnia, or set a sleep-restriction schedule. That is a clinician's decision.
  • Start empty when the store is unreadable. An empty list would read as “there is nothing to worry about”.
  • Use a key or a network. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA worry with no text or no window is refused, with the empty field named. A night that adds up to no sleep is refused.
No networkNothing changes; the app never calls out, so there is no offline message to show.
Storage full or unavailableThe save fails loudly, the text stays in the box, and the worry is never shown as set aside.
Corrupt saved stateReported as unreadable, with the raw text offered for export before anything is reset.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — both specs' countable claims are asserted there.
